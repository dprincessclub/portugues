# Português: курс из дневника Арины (от нуля до B1)

Личный сайт для изучения бразильского португальского. Без сервера и регистрации: всё работает в браузере, данные хранятся на твоём устройстве.

## Что нового в версии «Вне сети»
- Оформление в стиле канала «Вне сети»: изумруд, бордо и молочный, шрифты Cormorant Garamond, Montserrat и Caveat, узор азулежу.
- «Frase do dia» — тёплая фраза дня на португальском с переводом и подсказкой по языку (40 фраз).
- «Как пишут в бразильских чатах» — сленг из переписки: kkkkk, sdds, deixar no vácuo и другие (20 выражений, кнопка «Ещё одно»).
- Похвала по-бразильски вместе с конфетти: «Arrasou!», «Mandou bem!» и другие.
- Приветствие Арины при первом входе и ссылка на дневник @dprincessclub.

Фразы, сленг и похвала лежат в конце `data.js` (`FRASES`, `CHAT`, `ELOGIOS`) — их легко дополнять.

## Файлы
- `index.html` — каркас страницы
- `style.css` — оформление
- `data.js` — программа курса (24 юнита), ресурсы и методики. Здесь можно править слова, тесты и добавлять свои юниты
- `app.js` — вся логика (словарь, повторения, прогресс, напоминания)

## Как открыть на компьютере
Положи все 4 файла в одну папку и открой `index.html` двойным кликом. Для шрифтов нужен интернет, без него сайт тоже работает, просто с обычными шрифтами.

## Как выложить на GitHub Pages
1. Создай репозиторий на github.com (например, `portugues`).
2. Нажми «Add file», затем «Upload files» и перетащи 4 файла (`index.html`, `style.css`, `data.js`, `app.js`). Нажми «Commit changes».
3. Открой «Settings», затем «Pages». В «Source» выбери «Deploy from a branch», ветку `main` и папку `/ (root)`. Нажми «Save».
4. Через пару минут сайт откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/portugues/`.

## Важно про данные
Прогресс и словарь лежат в браузере (localStorage), отдельно на каждом устройстве и в каждом браузере. Чтобы перенести на телефон: «Настройки», затем «Скачать копию данных», а на другом устройстве «Загрузить копию». Делай копию раз в неделю.

## Напоминания
- «Настройки», затем «Скачать напоминание для календаря»: файл .ics создаёт ежедневное событие, которое напомнит, даже когда сайт закрыт.
- Уведомления в браузере работают, пока вкладка с сайтом открыта.

## Как добавить свой юнит
В `data.js` скопируй любой блок внутри `UNITS` и поменяй `id` (например, `u25`), название, слова (`w`), фразы (`ph`), грамматику (`g`) и вопросы (`q`).
